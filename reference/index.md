# Package index

## Core Functions

- [`countPwmMatches()`](https://smped.github.io/motifTestR/reference/countPwmMatches.md)
  : Count the matches to a PWM within an XStringSet
- [`getClusterMatches()`](https://smped.github.io/motifTestR/reference/getClusterMatches.md)
  [`countClusterMatches()`](https://smped.github.io/motifTestR/reference/getClusterMatches.md)
  : Find matches from a PWM cluster within an XStringSet
- [`getPwmMatches()`](https://smped.github.io/motifTestR/reference/getPwmMatches.md)
  : Find all PWM matches within an XStringSet
- [`testClusterEnrich()`](https://smped.github.io/motifTestR/reference/testClusterEnrich.md)
  : Test enrichment across a cluster of motifs using a background set of
  sequences
- [`testClusterPos()`](https://smped.github.io/motifTestR/reference/testClusterPos.md)
  : Test positional bias motifs within a cluster
- [`testMotifEnrich()`](https://smped.github.io/motifTestR/reference/testMotifEnrich.md)
  : Test motif enrichment using a background set of sequences
- [`testMotifPos()`](https://smped.github.io/motifTestR/reference/testMotifPos.md)
  : Test for a Uniform Distribution across a set of best matches
- [`clusterMotifs()`](https://smped.github.io/motifTestR/reference/clusterMotifs.md)
  : Assign each motif to a cluster
- [`makeRMRanges()`](https://smped.github.io/motifTestR/reference/makeRMRanges-methods.md)
  : Form a set of random, matching ranges for bootstrapping or permuting
- [`plotMatchPos()`](https://smped.github.io/motifTestR/reference/plotMatchPos.md)
  : Plot Motif Match Positions

## Data Objects

- [`ar_er_peaks`](https://smped.github.io/motifTestR/reference/ar_er_peaks.md)
  : A set of peaks with AR and ER detected
- [`ar_er_seq`](https://smped.github.io/motifTestR/reference/ar_er_seq.md)
  : Sequences from peaks with AR and ER detected
- [`ex_pfm`](https://smped.github.io/motifTestR/reference/ex_pfm.md) :
  Example Position Frequency Matrices
- [`hg19_mask`](https://smped.github.io/motifTestR/reference/hg19_mask.md)
  : Regions from hg19 with high N content
- [`zr75_enh`](https://smped.github.io/motifTestR/reference/zr75_enh.md)
  : Candidate Enhancer Regions from ZR-75-1 Cells
